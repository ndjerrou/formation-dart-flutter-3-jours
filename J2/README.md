# J2 - Premiers pas avec Flutter

Les supports et le projet Flutter seront ajoutés à ce dossier pendant
la formation. Aucun projet Flutter n'est encore présent dans cette version.

Notions à aborder : lancer une application, lire un arbre de widgets,
composer un écran, afficher une liste et gérer des interactions.

Avant la séance, vérifier l'installation de Flutter :

```bash
flutter --version
flutter doctor
```
